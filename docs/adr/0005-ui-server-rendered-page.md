# 0005. Интерфейс — веб-страница, которую отдаёт FastAPI

**Статус:** принято, 2026-10-22

## Контекст
Интерфейс должен показывать варианты уточнения кнопками, сгенерированный SQL, таблицу
результата и принимать отзыв 👍/👎. Демо должно открываться по ссылке. Telegram-бот уже был
в предыдущем проекте автора; в этом проекте закрывается пробел «веб-часть».

## Решение
Одна страница: шаблон Jinja2 и немного JavaScript без сборки, отдаётся тем же FastAPI-сервисом,
который предоставляет JSON API. Слой `presentation` содержит и API, и страницу.

## Последствия
- Нет отдельного фронтенд-проекта, сборки и CORS.
- Telegram-бот или SPA можно добавить позже поверх того же JSON API.

## Отвергнуто
- Telegram-бот — плохо показывает SQL и широкие таблицы; повтор предыдущего проекта.
- SPA (React/Vue) — отдельный стек, отнимает время от LLM и безопасности SQL.
