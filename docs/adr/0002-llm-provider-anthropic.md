# 0002. Провайдер LLM — Anthropic, основная модель Claude Haiku 5.5

**Статус:** принято, 2026-10-20

## Контекст
Ответ модели — одно из двух: уточнение с вариантами или SQL (см. ADR 0001). Нужен
структурированный вывод с гарантией соответствия схеме. Промпт большой и повторяется
(схема + правила + few-shot ≈ 6–8k токенов), бюджет — несколько долларов в месяц, автор
в Казахстане.

## Рассмотренные варианты
Anthropic, OpenAI, Google Gemini, DeepSeek, Mistral. DeepSeek и Mistral отпали: они не
гарантируют соответствие JSON-схеме. Gemini документирует только синтаксически корректный
JSON. OpenAI сопоставим с Anthropic по цене и гарантиям.

## Решение
- Провайдер — Anthropic, официальный SDK `anthropic` (async-клиент).
- Основная модель — Claude Haiku 5.5; Claude Sonnet 5.5 — для сравнения на тестовом наборе.
- Структурированный вывод с гарантией схемы; ответ «уточнение ИЛИ SQL» — внутри объекта-обёртки.
- Явное кэширование постоянной части промпта (`cache_control`).
- Провайдер скрыт за интерфейсом `LLMClient` в слое `application`.

## Последствия
- Оценка стоимости: ~$0.40/мес для Haiku и ~$8/мес для Sonnet при 3 прогонах тестового набора в неделю.
- Сравнение моделей «точность против цены» на собственном тестовом наборе — часть README.
- Оплата API отдельная от подписки Pro (консоль Anthropic).
- Не проверено: принимает ли SDK discriminated union из Pydantic без обёртки.
